# Task

## 결정 사항

- 페이지 내용은 `data.json`을 읽어 JS로 구성한다. 내용 수정은 JSON만 고친다.
- 프로젝트 상세는 별도 페이지 없이 목록에서 펼쳐 보여 준다(세로 목록 아코디언).
- 이미지 등 프로젝트 자료는 `projects/<slug>/` 폴더에 둔다.
- 프로젝트 목록 위에 기술(`stack`) 필터를 둔다. 프로젝트 하나에만 쓰인 기술은 "기타"로 접어 둔다.
- 기술 필터의 "전체" 바로 오른쪽에 "주요" 토글을 둔다. `featured: true`인 프로젝트를 고르며, 기술 버튼과 함께 쓰면 고른 것 중 하나라도 해당하는 프로젝트를 보여 준다. 처음에는 꺼져 있으며 켜면 `?featured=1`로 남긴다.
- 기능 없는 장식 UI(제목 밑줄, 강조 막대, 번호 배지 등)는 두지 않는다.
- 프로젝트 정렬 드롭다운은 Projects 제목 줄 오른쪽 끝에 둔다. 시작 시간(가장 이른 `periods.start`) 기준 최신순이 기본이고, 오래된순은 `?sort=asc`로 남긴다.
- 언어 선택 드롭다운(English/한국어, 현재 언어 굵게)은 헤더 오른쪽 끝에 둔다. 처음 언어는 `?lang=ko|en`을 따르고, 없으면 브라우저 언어가 한국어일 때만 한국어로 보여 준다.

## 목표 구조

```
Portfolio/
├── index.html
├── style.css
├── script.js                   # 메뉴, 한/영 전환, data.json 렌더링, 기술 필터, 정렬
├── data.json                   # Projects, Contact 내용
└── projects/
    └── <slug>/
        └── (GIF 등 프로젝트 자료)
```

## 주의 사항

- 경로는 모두 상대 경로로 쓴다. `/`로 시작하면 `/Portfolio/`가 빠져서 깨진다.
- 로컬 확인은 `python3 -m http.server` 후 `http://localhost:8000`에서 한다. `file://`로 열면 `fetch`가 막힌다.
- JSON 문법 오류가 있으면 해당 섹션이 표시되지 않으므로 수정 후 반드시 확인한다.
- 파일 하나가 100MB를 넘으면 push가 거부된다. 긴 영상은 YouTube 임베드를 쓴다.
- `CLAUDE.md` 규칙: 승인 없이 UI 추가 금지, 커밋 전 사용자 검토.
